| Does NOT contain | tuition, admission requirements, application deadlines, programme web page. These must come from each university |
| Update frequency / coverage | `lastRefresh` per record; academic-year coverage is by instance start date (not by cycle), so a new intake is a new or updated instance |
| Licence / reuse | **not confirmed**: the open-data terms of RAD-on were not found on the pages searched (search returned nothing authoritative). The data is published for reuse as public-sector open data under the Act of 11 Aug 2021 on open data; the exact licence/attribution wording must be confirmed in writing (RAD-on / OPI contact) before storing a refreshed copy |
| Suitability | Good for identity, level, language, ECTS, status and discontinuation monitoring (weekly refresh). Not a source of fees or deadlines. English-language instance in POL-on is necessary but not sufficient: every shortlisted programme was checked on the university's own page |

## 5. Rules for any new country connector
Official source first; licence/terms confirmed in writing before storing a refreshed copy; stable external identifier; level classification by coded fields, never by name; academic year only when the source states it (published fees without a year stay undated); English-language instruction confirmed on the university's own page; link monitoring and review queue reused unchanged.
